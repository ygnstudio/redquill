# MDQuill 使用指南

- 版本：v0.1.0（2026-09-03）
- 定位：在 Obsidian 里舒服地写 md——粘贴净化、中文排版体检（一键修复）、右侧栏写作仪表盘
- 同类边界：不做「课程/模板/学习」；不管公文章节排版（那是 [RedHead](https://github.com/ygnstudio/obsidian-redhead) 的活）

---

## 一、安装

1. 已装 [BRAT](https://github.com/TfTHacker/obsidian42-brat)：命令面板「BRAT: Add a beta plugin」→ 填 `ygnstudio/mdquill` → 启用
2. 手动：从 [Release](../../releases) 下载 `main.js` / `manifest.json` / `styles.css` 放入 `.obsidian/plugins/mdquill/`，重启 Obsidian 后启用

> `isDesktopOnly: false`，手机/平板端可用（命令齐全；自动净化粘贴的「设置开关」在移动端同样生效）。

## 二、命令一览

| 命令 | 做什么 | 常用时机 |
|---|---|---|
| 粘贴并净化 | 读剪贴板（html 优先）→ 清洗 → 插入光标处 | 从网页/Word/WPS/公众号复制内容过来时 |
| 清洗选区 / 当前段 | 不清剪贴板：把选中文本（或光标所在行）清洗后替换 | 已粘贴进来才发现格式脏；行首有手敲空格/多余空行 |
| 排版体检（当前笔记） | 八条规则全文自查，弹报告（分级、行号可点跳） | 写完一段/一篇后 |
| 一键修复排版问题 | 只自动修无歧义项，逐行 replaceRange（Ctrl+Z 可逐行撤销） | 体检报告说「可一键修复」时 |
| 打开写作面板 | 右侧栏仪表盘（五卡） | 长文写作、实时看体检计数 |

侧栏图标：羽毛笔（pen-tool）= 打开写作面板。

## 三、粘贴净化

清洗内容（网页/Word/WPS 粘贴最脏的几类）：

- 剥 HTML 全部标签、`<script>`/`<style>`/注释整体剔除
- 行首尾空白剥除（普通空格、全角空格 U+3000、NBSP、制表符）
- 空行压缩：段间恰好空一行（md 段落约定）
- 实体解码（`&nbsp;` `&amp;` 数字实体等）
- html 来源行内连续空白折一空格（Word 空 `<span>` 串、`&nbsp;` 连发残留）

**不做**：不合并行、不改行内文字（专名/数字间空格保留）——粘贴是「排版脏数据规整」，不是改写。

剪贴板权限说明：命令式读取剪贴板依赖系统权限。若提示「读不到剪贴板」，直接粘贴后再运行「清洗选区 / 当前段」（该命令不碰剪贴板）。

自动净化粘贴（设置开关，默认关）：开启后编辑器内粘贴带格式 HTML 自动清洗插入；纯文本粘贴直通不处理；无变化也不拦截。保守起见默认关，建议先习惯命令，确实频繁再开。

## 四、中文排版体检（八条规则）

| 规则 | 级别 | 自动修 | 说明 | 示例 |
|---|---|---|---|---|
| repeated-punct | error | ✅ | 重复标点连发 | 「你好。。。」→ 折叠为「。」 |
| punct-mix | error | ✅ | 中文句内半角标点（, . ; : ! ? ( )），含中文标点后接半角（如「）;」） | 「你好,世界」→「你好，世界」；数字/缩写/省略号/范围的半角点不误伤 |
| cjk-latin-space | warn | ✅ | 中文与拉丁字母相邻缺空格（数字除外） | 「用Obsidian写」→「用 Obsidian 写」 |
| bracket-mismatch | error/warn | ❌ | 括号引号配对：中文括号不成对 error；引号疑似未闭合、半角括号不成对 warn（引文跨行可忽略） | 「他说（注意」报 error |
| straight-quote | warn | ❌ | 中文语境出现直引号 " ' | 「他问"你是谁"」建议用“ ” |
| dup-word | warn | ❌ | 疑似叠字笔误（的的/了了/是是/在在…） | 「这个的的问题」 |
| control-char | error | ✅ | 控制字符/零宽字符混入（多来自网页复制） | U+200B 等，一键清除 |
| fullwidth-space | warn | ✅ | 行内全角空格 U+3000 | 行首的删除、行内转普通空格 |

**保护机制**（扫描与修复共用，防误伤）：

- 代码围栏（```…```）内整段跳过
- 行内 code（`a,b`）、裸 URL（https://…）、md 链接（[文](url)）整段跳过
- frontmatter（---…---）整段跳过

修复原则：只自动修「无歧义」类（表内 ✅ 五条）；括号/引号/叠字类只报不修——它们可能是写法风格或引文跨行，交给作者判断。修复按行执行、可 Ctrl+Z 逐行撤销。

## 五、写作面板（五卡）

右侧栏「写作面板」实时跟随（200ms 防抖），内容随光标/输入刷新：

1. **字数**：中文 / 非空白 / 总字符 / 段数 / 光标所在行
2. **标点体检速览**：实时全文体检的 error/warn 计数；有则「看报告」弹完整列表，通过则显示「通过」
3. **标题树**：h1-h3 大纲，点击跳转该行；当前所在小节高亮（面板开着时不迷路）
4. **快捷插入**（光标处）：`# 标题` / 表格 3×3 / 引用 / 代码块 / 折叠块（callout）/ 待办项 / 分隔线 / 图片占位
5. **空文档引导**：空笔记时提示从 # 标题写起（不做模板灌输）

## 六、设置

| 项 | 默认 | 说明 |
|---|---|---|
| 自动净化粘贴 | 关 | 编辑器内粘贴带格式 HTML 自动清洗（见 §三） |

设置项刻意最少——体检规则、面板卡片都是定死的出厂集，不做逐项开关（防配置蔓延，真需要再谈）。

## 七、常见问题

**和 Linter / 各类 md 格式化插件什么关系？**
Linter 类做「全文规范重排」，范围大、可配置性强。MDQuill 只做三件小事：粘贴净化、中文排版体检+一键修复、写作仪表盘，全部围绕**中文写作场景**（Linter 默认配置不会管「，」半角混用和「用Obsidian」空格）。两者不冲突；觉得 MDQuill 的某条规则多余，目前只能忽略（warn 级不碍事）。

**修复会不会改坏我的代码块/链接？**
不会。代码围栏、行内 code、URL、md 链接在扫描与修复时整段保护（§四保护机制），断言覆盖。

**为什么数字不加空格（2026年 / 3.5）？**
中文与字母之间补空格是惯例；数字与中文在年份、数量、版本里语义一体，加了反而散。英文 token 尾接中文（如「CM6编辑器」）暂不处理，属已知边界，后续版本视反馈加。

**面板体检全文每次击键都扫，大文件卡吗？**
面板开着才扫，200ms 防抖合并；几万字符逐行正则在毫秒级。超大文件（十万+）会略慢，属可接受范围。
