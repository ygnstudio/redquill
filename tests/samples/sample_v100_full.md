# 关于做好秋冬季秸秆禁烧与综合利用工作的通知

各村（社区），镇直各单位：

为切实做好秋冬季秸秆禁烧和综合利用工作，持续改善大气环境质量，保障人民群众生命财产安全，根据《中华人民共和国大气污染防治法》和省、市、县关于秸秆禁烧工作的部署要求，结合我镇实际，现将有关事项通知如下。

一、总体要求

坚持"属地管理、源头防控、疏堵结合、综合利用"原则，实现全镇范围内秸秆"零焚烧、零火点"目标。各村（社区）为本辖区秸秆禁烧工作的责任主体，村党组织书记为第一责任人，要建立健全网格化巡查和应急处置机制，确保每块田地都有人看、有人管。

二、重点任务

### （一）强化宣传引导

秋收前各村（社区）要通过广播、微信群、公开栏、入户发放告知书等方式广泛宣传禁烧政策，做到家喻户晓、人人皆知。每村至少悬挂宣传横幅三条，张贴禁烧通告至每个自然村，与种植大户逐一签订禁烧承诺书。

### （二）落实网格巡查

实行镇干部包村、村干部包组、网格员包田块的三级包保制度。禁烧期间各村要成立不少于十人的应急扑火队伍，配备灭火工具，坚持全天候巡查值守，发现火点第一时间处置并上报。

### （三）推进综合利用

镇农业农村办公室牵头推广秸秆机械化还田、打捆离田和饲料化利用，对接秸秆收储企业到村设点收购。对主动开展秸秆离田利用的农户，按每亩二十元标准给予作业补贴。

三、责任分工

各单位要按照职责分工，密切配合，形成工作合力，具体任务分解如下：

| 责任单位 | 主要任务 | 完成时限 |
| --- | --- | --- |
| 镇党政办公室 | 统筹协调、督查通报 | 全过程 |
| 镇农业农村办公室 | 技术指导、还田验收、补贴兑现 | 11 月底前 |
| 镇综合执法队 | 火点巡查、执法处罚 | 禁烧期内 |
| 各村委会 | 宣传发动、网格值守、应急处置 | 禁烧期内 |

四、考核与纪律

镇政府将秸秆禁烧工作纳入各村年度绩效考核，实行"日巡查、周通报、月评比"。对发生全镇第一把火或造成不良影响的村，取消当年评先评优资格，并依规依纪追究相关责任人责任。禁烧期间镇里设立举报电话并向社会公布，对举报属实者给予奖励。

各村（社区）接此通知后，要于三日内召开专题会议部署落实，并将包保责任清单报镇党政办公室备案。工作中遇到的重大情况和问题，请及时报告。

# 附件：云溪镇秸秆禁烧值班巡查安排表

一、值班安排

禁烧期间实行镇村两级二十四小时值班制度。镇级值班由镇党政办公室统一排班，每日明确一名带班领导和两名值班人员；村级值班由各村自行安排，值班表报镇党政办公室备案。

二、巡查线路

镇综合执法队每日分东西两片开展巡回检查，重点巡查国省道沿线、种植大户连片田块和往年火点多发区域。巡查情况实行日报告制度，每日下午五时前报镇值班室汇总。

三、应急处置

接到火情报告后，值班人员要立即通知所在村应急队伍赶赴现场，做到"早发现、早处置、早扑灭"，火点处置情况在两小时内书面报镇党政办公室。对故意焚烧秸秆的行为，由镇综合执法队依法依规查处。
